# Issue

**环境**
- 系统版本：Ubuntu 26.04
- Python版本：3.14
- 包版本：sdt-tool v0.10

**复现命令**
1. `sdt-tool --count -1`

**预期结果**
报错并以非零退出码退出

**实际结果**
循环不执行，退出码为0

# 提交信息

**fix: 修复负数count导致静默成功**
问题：`--count -1` 时循环不执行，但退出码仍为0
方案：在参数校验中拒绝负数，以退出码2退出

# 评审意见

标注：Blocking
具体行为：负数 count 未校验，静默成功。
风险：用户误以为任务已执行，自动化程序出错。
建议动作：增加 if a.count < 0: parser.error(...)。
